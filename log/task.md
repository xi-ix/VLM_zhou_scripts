# 交通违章图像数据集自动化爬取与清洗任务书

## 1. 任务背景与目标

你需要开发一个基于 Python 的自动化工作流脚本。该脚本的任务是从公开网络获取图像，并利用本地部署的多模态大模型对图像进行零样本（Zero-shot）分类与清洗，最终构建一个高质量的“非机动车与行人交通违章”静态图像数据集。

## 2. 运行环境与硬件约束

代码必须严格适配以下本地运行环境，注意资源控制：

* **核心模型**：本地调用的视觉大语言模型为 **VLM/model_weights/Qwen3-VL-4B-Instruct**。

## 3. 核心工作流设计

脚本需要实现一个完整的数据流水线（Pipeline），包含以下四个阶段：

### 阶段一：图像采集（Image Acquisition）

* 编写轻量级爬虫（如使用 `Playwright` 或请求公共搜索引擎/图库 API），检索关键词矩阵（例：“电动车 没戴头盔”、“行人 翻越护栏”等）。
* 将原始图片下载至本地 `raw_data/` 目录。
* **要求**：加入基础的异常重试机制和超时处理，过滤掉小于 50KB 的无效小图。

### 阶段二：数据预处理与去重（Deduplication）

* 使用 `imagehash` 库计算图像的感知哈希值（pHash）。
* 比对哈希值，自动删除高度相似或重复的原始图像，确保数据集的多样性。
* 将图片统一转换为 RGB 格式的 `.jpg`，防止 RGBA 或 WebP 格式在模型推理时报错。

### 阶段三：VLM 自动化清洗（VLM Filtering）

* 加载本地的 Qwen 模型。
* 遍历去重后的图像，将图像和特定的 Prompt 送入模型推理。
* **系统提示词（System Prompt）模板**：
```text
你是一个交通违章判定专家。请观察这张交通监控图片，判断是否存在以下违章行为。
请严格按照 JSON 格式回复，不要包含任何多余的解释或前缀。

{
  "has_violation": true/false,
  "category": "helmet / overload / pedestrian_red_light / crossing_barrier / none",
  "confidence": <0.0到1.0之间的浮点数>
}

判定标准：
1. helmet: 有人骑电动车或摩托车，且明显没有戴头盔。
2. overload: 一辆两轮电动车上搭载了2个或更多成年人。
3. pedestrian_red_light: 画面中包含红色的行人信号灯，且有行人正在斑马线或马路上违规行走。
4. crossing_barrier: 有行人正在用身体跨越、攀爬或翻越马路中间的物理隔离栏。
5. none: 无上述明显违章，或图片与交通场景无关。

```



### 阶段四：自动化分类与存储（Data Routing）

* 编写 JSON 解析函数，提取模型输出的结果。
* 如果解析失败，使用正则表达式兜底提取，或将图片移入 `errors/` 目录供人工核对。
* 根据解析出的 JSON 结果：
* 若 `has_violation` 为 `true` 且 `confidence >= 0.8`，将原图移动至 `dataset/<category>/` 对应目录下。
* 若为 `false` 或分类为 `none`，直接删除该图以节省存储空间。
